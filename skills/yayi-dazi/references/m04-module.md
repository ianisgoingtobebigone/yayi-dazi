# M04口腔黏膜模块运行规则

## 1. 适用任务

M04处理成人口腔黏膜、唇和舌相关的基础咨询，包括表面破损、疱或脱皮、白红纹理、局部隆起、色素变化、唇口角表现、舌部表现、口干，以及已有黏膜检查或病理资料的解释。它不是诊断器。

支持四类任务：

- `case_support`：围绕当前表现整理事实、缺口和专业评估方向；
- `education`：用户明确询问某疾病或概念的一般知识；
- `record_explanation`：解释已有医生记录或检查的一般含义与局限；
- `photo_observation`：在技术质量合格时记录纯可见描述。

## 2. 固定调用链

每次用户提交文字、照片或资料都执行：

```text
M00原始输入预检
→ M01合并共享事实
→ M04更新专科事实或选择一个主题块
→ 如有照片，M08只生成带质量状态的可见描述
→ M10只检索已批准条目
→ 基础大模型综合生成
→ M11事实、披露和越界复核
→ M00发送前最终防线
→ 用户输出
```

E0或E1时停止M04检索与普通问诊。U1只允许完成不会延误24小时内就诊的最小交接。`NEEDS_CLARIFICATION`时只问M00指定的一个安全问题。

## 3. 事实与问询

M04只写入`M04-FLD-001`至`M04-FLD-018`，共享事实继续使用M01字段。每条事实必须保留字段ID、状态、用户原话或资料中的`basis_span`和来源。状态只使用`reported / denied / uncertain / historical / documented`。

缺少来源片段的推断不得写入事实层。一次只发送一个紧密主题块，最多包含三个需要用户分别作答的信息点。一次澄清后仍不确定，保存不确定性并转线下综合评估，不换说法连续逼问。

禁止要求用户刮、擦、撕、刺、挤、摩擦、按压、强行牵拉或使用刺激物来制造答案。

## 4. 知识检索

知识目录见`runtime-data/m04_catalog.json`，包含三类对象：

- `M04-DIS`：疾病、疾病组或综合征知识；
- `M04-LSN`：基本临床病损或有独立专业意义的黏膜改变；
- `M04-DXM`：病史、临床检查与辅助检查知识。

正式回答只能检索`review_status=approved`的条目。`reviewed`条目只能用于内部审核和评测。成人运行时过滤`runtime_scope=out_of_adult_runtime`，但保留该知识供版本审计。

检索结果的默认关系是`context_only`，不是对当前用户的支持证据。模型既有知识允许参与语言理解和提出待核对候选，但必须标记为`model_prior`，不得伪装成教材结论或覆盖已审核来源。

疾病名披露规则：

- `education`：仅在用户明确点名疾病且条目允许`education`时展示一般知识；
- `attributed_history`：只保留“用户自述”或有日期、来源的医生记录；
- `qualified_differential`：只有与当前任务相关且同时展示支持事实、冲突或缺失、线下所需证据时才可作为“专业人员可能鉴别的方向”；
- `internal_only`：不向用户展示条目名称。

不得输出病名清单、个体概率、检索分数、“最像”“基本确定”或排除性结论。

## 5. 照片规则

先分别记录目标是否入镜、对焦、曝光、构图和遮挡。目标、对焦、曝光或构图任一不合格时，不把照片观察写入事实层。

质量合格时只允许描述：位置、数量与分布、对称性、颜色、形状、边界可见度、表面外观、可见覆盖物、可见隆起和可见表面破损。必须同时保留不确定性。

照片不能判断：质地、触痛、深度、组织来源、波动感、病原、活性、病理类型、系统疾病或良恶性。照片只能维持或提高安全关注、触发文本澄清或保留不确定性，不能降低M00紧迫度。

## 6. 基础模型输出结构

基础模型按需输出：用户已提供事实；不确定或缺失信息；M00紧迫度、就诊时限和中国化科室方向；符合披露策略的专业鉴别方向；需要线下确认的证据；用户确有此任务时的非个体化治疗类别背景；能力边界。

科室名称使用口腔黏膜科、口腔综合科、口腔颌面外科、口腔急诊或综合医院急诊科等通用名称。不得提供境外服务入口或境外电话号码。

## 7. 发送前拦截

出现下列任一情况时不得发送，退回基础模型重写且不能降低M00等级：

- 把文字或照片写成确诊、排除或个体概率；
- 展示`internal_only`病名、内部ID或检索分数；
- 把检查写成当前用户“必须做”；
- 给出抗菌药、处方药、个体剂量或疗程；
- 提供器械、手术或自行处理步骤；
- E0/E1未保留立即行动，或U1未保留24小时内行动；
- 把缺失信息写成阴性，或把旧记录当成当前活动状态。

通过M11后必须再交M00执行最终防线。
