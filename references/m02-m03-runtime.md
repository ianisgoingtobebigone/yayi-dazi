## M02

- 字段范围：M01共享字段及M02的16个专科字段。
- 处理：疼痛/敏感、自然刺激后的变化、咬合相关不适、牙体可见变化、同区软组织表现、治疗后时间线和既有记录。
- 只输出事实分组、M00复核请求、线下未决事项、M11路由和基础模型约束。
- 不确定患牙、牙髓状态、结构深度、咬合/松动、同区软组织来源或历史记录的当前意义时，使用具体`offline_assessment`，不猜测结论。

## M03

- 字段范围：M01共享字段及M03的17个专科字段。
- 处理：牙龈出血、可见变化、局部隆起/破损/流液、退缩、主观松动、牙位变化、清洁/异味、行为背景、既往照护和已有牙周记录。
- 只输出事实分组、M00复核请求、线下未决事项、M11路由和基础模型约束。
- 袋深、附着、骨水平、松动度、病名、分期、分级、进展速度和预后均属于线下专业评估范围。

## 共同顺序

```text
M00 → M01事实 → M11路由 → M02或M03
    → 条件M08 → 新图像事实回M00
    → M10 → 条件M09 → 基础模型 → M11 → M00 final_guard
```

共同约束：每轮最多一个问题块，每块最多三个紧密相关的信息点；未知不转为否认，旧记录不转为当前阳性，普通照片不降低紧迫度或替代专业检查。

专业字段编号本身不自动触发安全升级。只有结构化后形成新的安全事实组合，并明确携带有依据的字段时，适配器才返回`m00_recheck_required=true`；M11随后暂停后续模块，取得新的M00结果后再继续。
