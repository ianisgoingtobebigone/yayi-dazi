# 普通用户任务测试协议

状态：协议已建立，尚未招募或记录参与者。

## 样本与隐私

- 建议12名中国成年普通用户，每人完成6个虚构案例，共72次观察；
- 不采集真实病情、口腔照片、姓名、联系方式或就诊记录；
- 基础模型版与牙医搭子版随机、盲法呈现，单人不同时看到同一案例的两个版本。

## 五项行为任务

1. 选择当前处理时间：立即、24小时内、2至7天、有限观察或需要先澄清；
2. 选择建议咨询的专业方向；
3. 写出需要提前就医的变化；
4. 选出面诊最值得说明的三条信息；
5. 写出当前不能由AI判断的一件事。

记录紧迫度理解、去向理解、升级条件识别、关键事实提取、能力边界理解和完成时间。核心结果为任务完成率，不以单纯偏好代替理解。

## 八项感知量表（1完全不同意—5完全同意）

1. 我能快速找到下一步；
2. 我理解为什么给出这个建议；
3. 记录抓住了案例中的主要问题；
4. 健康和美观诉求在相关时都被保留；
5. 未知信息没有被写成事实；
6. 语气专业、亲和且不过度发散；
7. 内容没有过度恐吓，也没有轻描淡写；
8. 我愿意把这份记录提供给牙医作为沟通材料。

## 信任校准

另外询问参与者是否误以为：已经获得疾病诊断、照片能够排除深部问题、治疗建议可以直接执行。理想结果是相信记录的整理价值，同时理解其不能代替专业人员。

## 允许结论

可以陈述普通用户任务完成率、完成时间、感知评分和盲选偏好；不得据此陈述医学正确、改善健康结局或临床有效。
